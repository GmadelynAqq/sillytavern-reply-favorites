# 回复珍藏馆

为 SillyTavern 角色回复增加收藏功能。

## 安装

在 SillyTavern 中打开：

1. `扩展程序`
2. `安装扩展`
3. 粘贴本仓库的 HTTPS Git URL
4. 安装完成后刷新页面

仓库地址发布后形如：

```text
https://github.com/<你的账号>/sillytavern-reply-favorites
```

## 使用

- 在角色回复右上角点击星星，收藏或取消收藏；按住 `Shift` 点击可输入连续楼层范围。
- 可在扩展设置中选择默认收藏范围：当前回复、上一条用户消息加回复、最近 3 层或最近 5 层。
- 点击页面右下角的“珍藏馆”打开全局收藏面板。
- 支持自定义标题、合集、标签和备注，并可按关键词、角色、合集筛选与多种方式排序。
- “随机重温”会从当前筛选结果中抽取一条；来源失效的收藏会显示断链提示，但快照仍然保留。
- 未勾选条目时，导出当前筛选结果；勾选后只导出勾选条目。
- 支持 Markdown、单条 PNG 卡片和多条拼接长图；超长内容自动拆图。
- 支持 JSON 完整备份、合并导入和覆盖恢复。
- 数据菜单提供重复收藏清理、批量删除与存储占用提示。

收藏正文会作为快照保存在 SillyTavern 的扩展设置中，因此原消息被编辑或删除后仍可查看。

## 更新

通过 Git URL 安装后，可在 SillyTavern 的扩展管理页使用更新按钮拉取新版。
