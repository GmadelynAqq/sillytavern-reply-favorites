# 回复珍藏馆

为 SillyTavern 角色回复增加收藏功能。

## 安装

在 SillyTavern 中打开：

1. `扩展程序`
2. `安装扩展`
3. 粘贴本仓库的 HTTPS Git URL
4. 安装完成后刷新页面

安装地址：

```text
https://github.com/GmadelynAqq/sillytavern-reply-favorites
```

## 使用

- 在角色回复右上角点击星星，收藏或取消收藏；按住 `Shift` 点击可输入连续楼层范围。
- 可在扩展设置中选择默认收藏范围：当前回复、上一条用户消息加回复、最近 3 层或最近 5 层。
- 点击页面右下角的“珍藏馆”打开全局收藏面板。
- 支持自定义标题、合集、标签和备注，并可按关键词、角色、合集筛选与多种方式排序。
- 珍藏馆正文沿用 SillyTavern 当前的消息格式化流程，因此已启用的显示正则也会生效。
- “随机重温”会从当前筛选结果中抽取一条；来源失效的收藏会显示断链提示，但快照仍然保留。
- 未勾选条目时，导出当前筛选结果；勾选后只导出勾选条目。
- 支持 Markdown、单条 PNG 卡片和多条拼接长图；超长内容自动拆图。
- PNG 可选择稳定的“珍藏卡片”模式，或实验性的“跟随当前酒馆楼层美化”模式。后者会复刻当前角色/用户楼层的 CSS、背景图、头像和排版，并先将可读取的外链装饰素材内嵌到页面，再放入导出画布。
- 单条收藏始终只生成一个 PNG；导出期间会锁定按钮，避免手机双击或重复监听造成重复下载。
- PNG 图片支持暖茶、夜幕、森野、素墨四种主题，可切换背景预设或使用自定义颜色。
- 图片顶部的主标题、副标题以及是否显示导出日期均可修改。
- 支持 JSON 完整备份、合并导入和覆盖恢复。
- 数据菜单提供重复收藏清理、批量删除与存储占用提示。

收藏正文会作为快照保存在 SillyTavern 的扩展设置中，因此原消息被编辑或删除后仍可查看。

“跟随当前酒馆楼层美化”依赖当前启用的主题与美化 CSS。扩展会主动读取并内嵌楼层、头像和 `::before` / `::after` 伪元素使用的图片，并把图片伪元素实体化后再截图，以保留负层级和大型装饰；若素材源明确禁止浏览器读取，个别远程素材仍可能无法进入图片。若整个楼层复刻失败，扩展会自动回退到“珍藏卡片”模式，保证仍能导出正文。

## 更新

通过 Git URL 安装后，可在 SillyTavern 的扩展管理页使用更新按钮拉取新版。

## 仓库结构

```text
.
├── manifest.json
├── index.js
├── style.css
├── vendor/
│   └── html-to-image/
└── README.md
```

楼层复刻使用 vendored [`html-to-image`](https://github.com/bubkoo/html-to-image)（MIT License），许可证见 `vendor/html-to-image/LICENSE`。
